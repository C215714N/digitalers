Formularios HTML

Son elementos que permiten la interaccion entre el cliente (navegador) y el servidor, ya sea para enviar o recibir datos. Se implementan dentro de una pagina utilizando la etiqueta <form> y colocando dentro de la misma todo los elementos que pertenezcan al mismo. Cabe destacar que solamente se enviaran los datos que se encuentren dentro de este, caso contrario, estos no llegaran a destino.

¿Como funcionan?

A la etiqueta mencionada anteriormente debemos indicarle por los menos 2 atributos, action="..." el cual indica que debe suceder cuando se realiza el envio del formulario; y method="..." que especifica como se realizar el envio del mismo, es decir, cual de los metodos siguientes debe utilizar.

  • GET: metodo poco seguro, debido a que la informacion es visible desde la barra de direccion, pero mucho mas rapido; cuya prioridad radica en la respuesta del servidor. Se utiliza principalmente en buscadores
  • POST: metodo mas lentom y seguro, debido a que la prioridad radica en la proteccion de los datos enviados por el cliente, ya que estos se cifran antes de realizar el envio. Se utiliza en formularios de registro, sesion, contacto, etc...

¿Como estan compuestos?

En el interior del mismo podemos colocar elementos como Etiquetas (LABEL) que funcionan a modo de rotulo, indicando que se debe seleccionar y/o completar; y Campos (INPUT/SELECT/TEXTAREA) que corresponden a los elementos con los que el usuario interactua, estos al menos deben poseer algunos de los siguientes atributos para ser funcionales.

  • type utilizado en los input, indica que tipo de campo es el que se debe utilizar, por ejemplo number para numeros o checkbox para cuadros de opcion.
  • name identifica al campo de formulario, para utilizar su valor cuando este sea enviado. Varios campos pueden compartir nombre, indicando que corresponden a la misma opcion.
  • value corresponde al dato enviado, normalmente es implicito, pero podemos establecer un valor predeterminado en caso de ser necesario.

Pueden obtener mas informacion sobre formularios en W3Schools

Contenido Multimedia

Originalmente podiamos incorporar solamente imagenes de forma nativa, pero con la aparicion de HTML5 se agrego una compatibilidad nativa al lenguaje para elementos como musica y videos; es decir, que ya no es necesario descargar ningun complemento para reproducir este tipo de contenidos en el navegador web.

¿Nativo y Sin Plugins?

Como se menciona anteriormente, hoy en dia, los navegadores permiten agregar este tipo de contenido gracias a las etiquetas <audio> y <video> que soportan los formatos .mp3, .wav, .ogg y .mp4, .webm, .ogv respectivamente. Ademas podemos especificar atributos como controls, autoplay, muted, loop, etc... para cambiar caracteristicas del reproductor y como se muestra en pantalla, segun sea necesario.

¿Contenido Embebido?

Como se menciona en el apartado anterior, antes era necesario descargar algun plugin de terceros para poder reproducir este tipo de contenidos. En la actualidad tambien podemos incorporar contenido desde otros sitios web, siempre y cuando sea con autorizacion del autor original, gracias a una categoria que recibe el nombre EMBED. Normalmente lo haremos gracias a que se incluye una opcion con el nombre compartir, incrustar o similar en el sitio original; permitiendo agregar una etiqueta <iframe> a nuestra pagina.

Se puede verificar la compatiblidad de estos elementos en el sitio Can I Use, ingresando el nombre en el buscador.

Tablas HTML

Son elementos que permiten organizar los datos de manera tabular y utilizan el modelo de cajas para su representacion debiendo colocar la etiqueta <table> para la creacion de las mismas y dentro de esta, las etiquetas <tr> y <td> que corresponden a las filas y celdas, respectivamente.

¿Poseen Estructura semantica?

En la version actual de html5, se incorporaron nuevas etiquetas,que permiten identificar las partes de la tabla, facilitando la organizacion de los datos y dicha estructura se compone de las siguientes etiquetas:

  • THEAD: corresponde a la fila de encabezados, que indica cuales son los datos a representar. En su interior se utilizan celdas de encabezado <th> (table heading)
  • TBODY Es el cuerpo de tabla y contiene los datos a representar, normalmente se divide en multiples filas y, en algunos casos, puede conteneder celdas de encabezado.
  • TFOOT Parte opcional de la tabla que posee informacion complementaria al cuerpo, como por ejemplo, totales, promedios u otro valores generales.

¿Celdas combinadas?

En caso de ser necesario, podemos expandir el tamaño de una celda, ya sea, de manera horizontal o vertical con los atributos colspan="..." y rowspan="..." respectivamente. Debemos tener en cuenta que el contenido posterior sera desplazado a la derecha de las celdas ocupadas.
