# Lenguajes de Programacion

Es un sistema que posee una sintaxis determina cuya finalidad es el desarrollo de aplicaciones, mediante la indicacion de instrucciones. Los mismos se pueden clasificar segun su implementacion o la manera en la que se crearon programas con estos.

* __FrontEnd__: Corresponde al desarrollo del lado del cliente, es decir, cualquier caracteristica de una web, que puede ser interpretada y reproducida por el navegador. Entre dichas caracteristicas encontramos.
    | Lenguaje | Descripcion |
    |-|-|
    | __HTML__ | Lenguaje de Marcado de Hipertexto _(Estructura)_ |
    | __CSS__ | Hojas de estilo en cascada _(Diseño)_ |
    | __JavaScript__ | Lenguaje de programacion interpretado por el navegador _(logica)_ |

## Implementacion
    
* __Escritorio__ Corresponden a los programas que se instalan sobre el sistema operativo como Windows con C++
* __Movil__ Programas que funcionan en los dispositivos moviles que utilizan su propio SO como Android o IOS.
* __Web__ Son aquellos que se ejecutan desde el navegador, independientemente del sistema operativo.
* __Consola__ Aplicaciones que funcionan desde la linea de comandos y por lo tanto, no poseen interfaz grafica.

## Forma de Creacion

* __Interpretado__ Lenguaje cuyas instrucciones son ejecutadas directamente por un programa, como por ejemplo el navegador con js.
* __Compilado__ Aquellos que empaquetan el codigo resultante en un archivo ejecutable como c++, o java
* __Transpilado__ Creados con algun framework o library que utiliza algun lenguaje que luego es traducido y compilado.
