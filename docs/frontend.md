## FrontEnd

Desarrollo del lado del cliente, es decir, cualquier caracteristica de una web, que puede ser interpretada y reproducida por el navegador. Entre dichas caracteristicas encontramos los siguientes lenguajes.

* __HTML__: Lenguaje de Marcado de Hipertexto _(Estructura)_
* __CSS__: Hojas de estilo en cascada _(Diseño)_
* __JavaScript__: Lenguaje de programacion interpretado por el navegador _(logica)_

## Lenguajes de Programacion

| Tipo | Descripcion | Ejemplo |
|-|-|-|
| __Compilado__ | No puede ser ejecutado directamente, se escribe el codigo en un entorno de desarrollo y luego este se prepara para ser ejecutado de un archivo, que debera compilarse nuevamente en caso de haber realizado cambios. | java |
| __Interpretado__ | En estos lenguajes el codigo es ejecutado directamente por algun programa, como el navegador, sin necesidad de compilar el mismo. Este se puede modificar y su codigo es legible en todo momento. | javascript |
| __Transpilado__ | Son aquellos lenguajes que poseen una sintaxis propia, pero para ser ejecutados su sintaxis se traduce y luego se compila a otro lenguaje que pueda ser interpretado por el programa que los utilice. | php |
