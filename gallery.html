Contenido Multimedia

En una pagina web, podemos incorporar cualquier tipo de elemento, como imagenes, musica y videos, brindando una mejor experiencia al usuario. Entre estos elementos encontramos las imagenes, que pueden corresponderse a los siguientes formatos.

  • JPG: Joint Photographic Experts Group, es un formato de imagen ligero, que admite compresion, y soporta por defecto hasta 16.777.216, pero no admite transparencia. Es ideal para fotografias y graficos complejos.
  • PNG: Portable Network Graphics, es una formato de imagen sin perdida, que admite compresion y transparencia. Es ideal para graficos con texto, logotipos y elementos que requieren alta calidad.
  • GIF: Graphics Interchange Format, es un formato de imagen que admite interpolacion y compresion sin perdida. Es ideal para graficos simples y animaciones cortas debido a que soporta hasta 256 colores.
  • WEBP: Web Picture Format, es un formato de imagen desarrollado por Google, pensado para la comparticion. Es ideal para web, ya que ofrece una buena calidad con un tamaño de archivo reducido.
  • SVG: Scalable Vector Graphics, es un formato de imagen que utiliza lineas y curvas para crear graficos escalables y animaciones, y es ideal para logotipos, iconos y graficos que requieren alta calidad en diferentes resoluciones.

Para incorporar una imagen en una pagina web, se utiliza la etiqueta <img>, que permite especificar la ruta del archivo de imagen y otros atributos como un texto alternativo en caso de no encontrar el archivo, y tambien para facilitar su indexado por parte de los motores de busqueda.
