FrontEnd

Corresponde al desarrollo del lado del cliente (navegador), es decir, toda caracteristica/lenguaje que pueda interpretar este sin necesidad de la intervencion de un servidor. Entre los diferentes lenguajes que podemos ubicar en este apartado, se encuentran:

  • HTML
  • CSS
  • JavaScript

HTML (HyperText Markup Language)

Lenguaje de Estructura que utiliza etiquetas para identificar a cada uno de los elementos que conforman una pagina web.
Las etiquetas puede poseer atributos y pueden clasificarse de la siguiente manera:

  • Bloque: Ocupan todo el ancho de su contenedor, generan salto de linea y funcionan principalmente como contenedores
  • Linea: Ocupan el ancho de su contenido, no se les puede dar tamaño, comparten linea con otros elementos de su tipo y funcionan principalmente como contenido
