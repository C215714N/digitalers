Desarrollo FrontEnd

Corresponde al desarrollo del lado del cliente, es decir, toda caracteristica que pueda ser reproducida por el navegador web del usuario; sin necesidad de la intervencion de un servidor web. Entre los lenguajes que forman parte de FrontEnd se encuentran los siguientes:

  • HTML
  • CSS
  • JS

HyperText Markup Language

HTML o Lenguaje de Marcado de Hipertexto se utiliza para definir la estructura de una pagina web. Utiliza etiquetas para identificar la funcion que cumple cada elemento dentro de la pagina.

Cascading StyleSheets

Las hojas de estilo en cascada se utilizan para definir el aspecto de los elementos de la pagina web. Utilizan selectores y reglas para indicar como deben lucir los mismos, entre los atributos principales se encuentan los siguientes:

  • margin: distancia que existe entre etiquetas
  • border: linea que rodea a las etiquetas (por defecto es 0)
  • padding: relleno que existe entre el borde y el contenido
  • content: corresponde al ancho y alto de los elementos
