Desarrollo FrontEnd

Corresponde al desarrollo del lado del cliente, es decir, toda caracteristica que pueda ser reproducida por el navegador web del usuario; sin necesidad de la intervencion de un servidor web. Entre los lenguajes que forman parte de FrontEnd se encuentran los siguientes:

  • HTML
  • CSS
  • JS
