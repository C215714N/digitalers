FrontEnd

Corresponde al desarrollo del lado del cliente (navegador), es decir, toda caracteristica/lenguaje que pueda interpretar este sin necesidad de la intervencion de un servidor. Entre los diferentes lenguajes que podemos ubicar en este apartado, se encuentran:

  • HTML
  • CSS
  • JavaScript

HTML (HyperText Markup Language)

Lenguaje de Estructura que utiliza etiquetas para identificar a cada uno de los elementos que conforman una pagina web.
Las etiquetas puede poseer atributos y pueden clasificarse de la siguiente manera:

  • Bloque: Ocupan todo el ancho de su contenedor, generan salto de linea y funcionan principalmente como contenedores
  • Linea: Ocupan el ancho de su contenido, no se les puede dar tamaño, comparten linea con otros elementos de su tipo y funcionan principalmente como contenido

CSS (Cascading StyleSheets)

Lenguaje de Hojas de Estilo en Cascada que se utiliza para definir la apariencia de los elementos que conforman nuestra pagina web. Utiliza selectores y reglas para definir el aspecto de los elementos afectados, el mismo se puede aplicar en linea o en bloque y dentro de las propiedades principales de las etiquetas, podemos encontrar las siguientes:

  • margin: Es el espacio que existe entre las etiquetas, no suma tamaño y siempre aplica el mayor.
  • border: Es la linea que rodea la caja de la etiqueta, por defecto su valor es cero.
  • padding: Corresponde al espacio que existe entre el borde y el contenido, tambien conocido como relleno; por lo general suele ser cero y suma tamaño.
  • content: corresponde al texto o elementos que se encuentran dentro de la etiqueta, a los que se les puede cambiar el tamaño con propiedades como width y height
